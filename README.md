Title: Source data for “Punishment shifts cooperation from local clustering to global diffusion”

Description:
This archive contains the numerical data underlying the main figures, supplementary figures, and table in the associated manuscript.

Contents:
- random_seeds.csv: independent seeds used for Monte Carlo replications.
- fig2/: source data for cooperation curves, Monte Carlo replications.
- fig3/:source data for fermi rule.
- fig4_fig5/: source data for network structural metrics and Table 1.
- fig6/: source data for the heterogeneity–punishment heatmaps.
- fig7/: source data for fixed, stochastic, and adaptive punishment simulations.
- supplementary/: source data for Supplementary Figs. S1–S9, table2.

Units and definitions:
Final cooperation is the average proportion of cooperating agents over the specified final simulation window. Detailed definitions and computational procedures are provided in the Methods section and code repository.
